HOW THIS BOARD READS

This command center displays the public daily snapshot from the original Grok Bots dashboard. It polls that file. It does not watch live processes.

  • SNAPSHOT CURRENT means the file timestamp is under 40 hours old.
  • STALE SNAPSHOT means that timestamp is older than 40 hours. The rows still show the last file.
  • LINK OFFLINE means the latest fetch failed. If a previous file loaded, it stays on screen.
  • NO SNAPSHOT means nothing has loaded. Counts stay blank rather than turning into zeros.
  • SOURCE UNKNOWN means the file arrived without a usable timestamp or a recognizable shape.
  • Week cells: filled teal = done (1), split amber = partial (0.5), crossed rose = missed (0), dashed = no data. Unrecognized numbers stay unlabeled.
  • Done, pending, and needs are lists in the file. A line in the done list is logged work, not a live success signal.
  • Year stays “no data” until the file itself carries a yearly note. This board does not invent an annual total.
  • The source has no machine-load fields, so there are no hardware gauges.
  • Search checks names, roles, routines, and list lines. Emails or secret-shaped values in a future file are redacted on screen.

KEYBOARD

  • / search
  • 1 command 2 agents 3 daily 4 week 5 year 6 feed 7 needs
  • F focus mode R refresh Esc clear filters, or close a panel
  • Left and right arrows move between agent records while a record is open.

Motion follows the operating system reduced-motion setting. The globe holds a still frame when that setting is on.
